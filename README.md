## 当前功能

- 导入同一案件的扫描 PDF 或 PDF、Word、图片混合材料。
- 文书识别、跨页归并、目录映射、字段提取与原页来源关联。
- 律所原表优先保留，缺少原件时按模板填充；疑点集中核对与补件继续。
- 草稿和确认版成果、PDF 目录跳转、书签、正文页码、Word 与 ZIP。
- DeepSeek 视觉 API、GLM 标准 API 适配及 Ollama 本地视觉模型选项；各路径需分别验收。
- 卷小助动画形象、对话入口、姓名工作空间及管理员密码入口。

姓名工作空间只是可信内部环境中的使用者区分，不是身份认证。不要将姓名模式直接暴露到公网。

## 在全新环境运行

推荐 Windows、Python 3.12 和 Node.js 20 或更新版本。完整原表 DOCX/PDF 渲染还需要可用的 Word 兼容 COM 组件；原开发环境使用 WPS，不能据此认为其他平台已经通过完整验收。

在项目根目录打开 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r web\backend\requirements.txt
cd web\frontend
npm ci
npm run build
cd ..\..
$env:V5_HOST = '127.0.0.1'
$env:V5_PORT = '8000'
.\.venv\Scripts\python.exe web\backend\run.py
```

打开 `http://127.0.0.1:8000`。首次初始化使用本机新生成的 `web/data/setup.token`，在本机打开 `/setup#token=该文件中的一次性值` 创建管理员；不要将该值上传到仓库或发送给其他人。没有随源码附送的生产账号、密码或 API Key。

模型密钥、模型地址及云端处理策略由管理员在新环境配置。不要直接复制旧数据库作为初始化方式。Ollama 服务与模型权重需要单独部署；完整文档转换组件也不在此源码包内。

根目录原有 `启动工作站.cmd` / `workstation_entry.py` 专门用于原电脑的既有 8766 工作站，要求已有数据库，故保留为历史兼容入口；**全新克隆请使用上述开发启动步骤**。本次打包没有停止或修改原工作站。
