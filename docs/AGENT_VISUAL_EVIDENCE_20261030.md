## 目的与范围

对应 PRD F05、F06，面向 A03—A05 复杂材料读取的部分基础能力。旧流程将视觉提取的字段与本地文字层/OCR逐字比较，OCR错字可能阻止正确的图像候选进入表单。本次增加有界的图像复核路径，同时保留原有文字校验路径。

实现不是模型训练，也不是两家独立模型投票。第一次提取可能同时看过图像和OCR，第二次使用同一服务商的新对话，只提供原图和待核字段名。两次一致不等于真实准确率，不证明签署、履行或材料真实性。

## 执行链条

1. 初次候选必须来自当前已看页面、允许字段及文书范围。字段值须在引用中；仅“引用与本地文字不一致”可进入本路径，字段语义不成立仍走原有复核。
2. 服务端冻结首次候选及来源SHA256。一个字段/页出现多个不同候选时，不以重复数量投票。
3. 使用现有一次定向复核步骤，新建仅含系统规则和本次原图的消息；不携带此前答案、OCR正文、成功字段或对话历史。重新附整页，必要时使用已有低清区域定位图；不重新OCR。
4. 模型返回限定字段与完整原页转录。不能完整读清或输出容量不足时，不得截断后声称完整。每页最多8000字，合计最多12000字，最多3个目标页。
5. 程序要求：两次字段值在既有文字规范化后相同；两次引用均被转录支持；既有主体、角色、条件、日期及结果等语义校验均通过；页面、文书、原件哈希一致，并有原页定位框。不能把模型自报清晰度当成唯一依据。
6. 采纳记录保存两次候选的关系、转录、原页坐标、来源哈希、版本及一致性摘要。保留原OCR，不覆盖原件；保留“未验证准确率”的状态。模型不得自行提交或伪造服务端采纳凭据。
7. 表单取值、字段依据提示和原疑点关闭均检查当前来源及凭据。人工留白、已有字段冲突、角色绑定规则继续生效。来源改变时旧凭据不再支持自动取值。

若两次图像值不一致，即使第二次碰巧与OCR相同，也继续待核，不在两个答案中任意挑选。

## 预算、失败与兼容

- 不增加每组现有5步上限；复核仍最多一次，没有第三轮投票或失败自动重试。
- 图像准备失败不发送这次复核；格式错误、越界字段、阅读不清、内容不一致或来源失效均保留待核。
- 请求次数上限不变，但重复附图和转录可能增加Token、延迟及费用，实际成本尚待模型验证。
- 旧OCR和视觉字段的兼容方法名继续保留；新增 `text_basis.method=image-only-field-readback-v1` 和 `visual_readback` 明确真正读取依据，不能将其解释为OCR交叉确认。
- 凭据摘要用于一致性检查，不是密码学签名或权限令牌；创建入口属于服务端已有受限提取流程，案件访问权限仍由现有接口负责。
- 第十八轮识别版本升级到v14，不能复用v4—v13识别快照冒充本次执行。此变更不会主动重跑现有任务。
- 原文字缓存不替换。第十八轮将已核字段的完整引用接入综合撰写，未将整页视觉转录开放为任意事实来源。依赖原OCR的跨页角色关联、其他字段召回仍需分别接入并实测。若另一来源仍产生不同值，冲突保留，不静默压掉。

## 第十八轮：综合撰写的字段来源衔接

原流程的综合撰写只读文字缓存。视觉字段采纳成功后，其正确值可能还不能进入归纳，反而再次使用该页有分歧的OCR。本轮新增 `visual_synthesis_sources.py`，在原有写作与审校两次请求内接入：

- 校验当前字段、未决冲突、原件哈希、文书范围及原采纳凭据，仅将已核字段的完整引用提供给撰写员。整个视觉转录及私有凭据不发送给写作模型。
- 每条来源标明支持哪个原字段、可用于哪些叙述栏目；不能把只核过身份的片段变成已完成工作。引文不得截去主体或条件；标量字段还要求表述中保留相应值。既有模型语义审校、数字、接案视角及容量限制继续执行。
- 在本次自动撰写来源池中隔离有明确视觉分歧的同页OCR，保留原缓存和原件。字段修改或冲突不能令原有错误OCR重新成为替代来源；换成不同哈希的原件后，旧凭据也不能影响新来源。
- 这一隔离可能减少该页其他未核内容的可用范围，因此只核字段的页面不计作完整阅读。实际使用这类引文的栏目强制保留 `incomplete_source` 质检项，不将缺口说明写进表格正文。仍需真实效果验证，不能宣称隔离后内容覆盖率一定提高。
- 保持72000字总取材预算和现有最多两次写作/审校请求。先保留明确字段依据，再在剩余预算中保留普通来源；不将有限引文用作整份文书的日期或金额提取依据。
- 生成内容绑定原字段凭据和当前来源。原字段改动、来源替换、凭据移除或冲突会使旧自动归纳失效；人工填写和明确留白保留。一个原文结果被同栏重新归纳时，保留其原输入依据，不把生成句子反过来当原件。
- 缺少当前来源范围时，不发起相关写作请求；写作过程中原件哈希变化时，不提交生成结果。待核字段值不再作为写作提示中的“已采纳身份信息”。

已验证：新来源协议11项；连同现有撰写、取材规则和台账共40项，后台来源/表单相关26项，经验及识别版本绑定36项。55个前端源码未改。

另用已有真实63页结构和第43页保存文字做17项离线接线检查，故意在内存改变OCR，使用本地回复适配器验证取材、两次写作预算、生成字段来源、表单投影及编辑失效。探针仅生成一条案号说明，**不是合格结案小结，也不作为文书质量或模型准确率验收**。本轮未重跑OCR、调用云端、渲染PDF/Word、部署或改变生产案件。

首次新单测夹具在主体名称后缺少句末分隔符，既有完整姓名边界校验拒绝采纳；补齐协议夹具后通过，未放松生产语义规则。
