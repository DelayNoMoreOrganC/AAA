# 原表填写契约

[内部模板来源路径已脱敏]

原生分页：审批表、送达清单、诉讼封面、非诉封面、结案报告各一页；质量卡连同委托人须知两页；五类目录各一页。LibreOffice 直接读取旧 DOC 会使部分底稿产生额外页，不能作为页数基准。

以 `word-converted/` 中 DOCX 为底稿。原表的页边距、节属性、表格属性、网格、合并格和边框均保持。原 DOC 部分行靠空段落撑高；为防填字引起框格变动，`layout-geometry.json` 记录原生 PDF 实测行高，统一锁为对应固定行高，并移除填写格中用于占高的多余空段落。这是明确的受控版式属性变更，不声称所有 trPr 字节不变。最终 PDF 框线坐标须与原生参考相差不超过 0.2 磅、原页数不变、全部填写文字可见。仅修改 `word/document.xml` 内上述属性与明确允许的文字槽，以及 `word/settings.xml` 的只读编辑保护；其他 ZIP 成员逐字节保留。具体物理槽及容量见 `original_template_service.SLOTS`。署名、意见、审批、送达记录、费用不得由模板生成器推断。

填字统一宋体 10.5 磅黑色；原有固定文字保留原格式。原格内可编辑区域用 Word 权限标记，固定格不可编辑。大段已有文字不硬截、不无限缩字。超限返回字段名供形成简明版本；PDF最终与原生底稿比较页数及框线坐标，并检查填写内容实际出现。

`word-reference-pdf/` 是原生 Word 导出的空白参考。质量卡原件的日期与投诉电话按本次用户明确要求保留；其来源属于历史原模板，不据此宣称规定现行有效。表格目录的 PDF 来源与 DOC 版本可能不同，具体取舍由目录服务单独记录。

验收使用 `artifacts/original-forms` 的纯虚构填写样例，需渲染每一页、核对框线和文本；不读取任何卷宗、账号设置或凭据。
